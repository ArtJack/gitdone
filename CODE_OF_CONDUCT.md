# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, argue about the work, and assume the other person is trying. Report anything that falls short to hello@artjeck.com with
`[gitdone conduct]` in the subject. Reports are read by the maintainer and kept private.
